Privacy Policy and Cookie Notice

This notice describes the current browser-only demonstration. It is not a statement that the demo is compliant with GDPR, POPIA, CCPA, or other privacy laws, and it is not legal advice.

What this demo stores

The app stores information in this browser using localStorage so its prototype features can work. Depending on what you use, this can include account details, profile fields, posts, messages, uploaded media, complaints, preferences, and moderation status. The demo login also stores passwords in browser storage as plain text. Do not use real passwords or sensitive personal information here.

Why it is stored

Local data supports sign-in simulation, profiles, feed and chat features, settings, complaint handling, moderation, and user-selected preferences. Optional activity logging adds limited event summaries and the associated account name to the local admin activity list only when you enable it. The log does not intentionally include message or post text, passwords, email addresses, phone numbers, or profile field values.

Cookie and storage notice

This static demo does not set browser cookies or use third-party analytics. It does use localStorage, which is browser storage and is not a cookie. A first-visit notice lets you allow or decline optional activity logging. You can change that choice at Settings → Privacy. Declining clears the local activity log and prevents new optional event entries; core app data remains stored so the prototype can function.

Sharing and security

This demo does not have a server account system. Data remains in the browser profile where it was entered and is not synchronized to an HYDROBOTICS service by this app. Anyone with access to this browser profile, or code running on this origin, may be able to access the stored data. localStorage is not encrypted credential storage. Do not upload identity documents or enter sensitive information.

The demo's identity review and sharing approvals are simulated in browser storage. They are not real identity verification and do not provide a production security boundary.

Your choices and deletion

You can opt out of optional activity logging at any time in Settings → Privacy. You can remove HYDROBOTICS data saved in this browser using “Delete data stored in this browser” in that section; this signs you out and clears the app's local data. You can also clear this site's browser storage through your browser settings. Deletion here does not remove copies, exports, screenshots, or information stored elsewhere.

Privacy rights and contact

Privacy laws such as the GDPR, South Africa's POPIA, and California's CCPA may provide rights concerning personal information, depending on your location and circumstances. This demo has no backend operator workflow to verify requests, fulfill statutory deadlines, or process formal rights requests. Before using this prototype with real people or data, the responsible organization should identify a privacy contact, define retention and security controls, and obtain jurisdiction-specific legal review.
