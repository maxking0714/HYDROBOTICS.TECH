Privacy Policy and Cookie Notice

This notice describes the current browser-only demonstration. It is not a statement that the demo is compliant with GDPR, POPIA, CCPA, or other privacy laws, and it is not legal advice.

What this demo stores

When Supabase is configured, it handles account credentials and authentication. The browser stores a Supabase session so you can remain signed in; browser storage is accessible to code running on this website's origin. Other prototype features may store profile fields, posts, messages, uploaded media, complaints, preferences, and moderation status in localStorage. Do not enter sensitive personal information while those features remain browser-only.

Why it is stored

Browser-stored preview data supports profiles, feed and chat features, settings, complaint handling, moderation, and user-selected preferences. Supabase Auth manages registration, sign-in, email verification, and password recovery when configured. Optional activity logging adds limited event summaries and the associated account name to the local admin activity list only when you enable it. The log does not intentionally include message or post text, passwords, email addresses, phone numbers, or profile field values.

Cookie and storage notice

This static site does not use third-party analytics. Supabase may use browser storage to maintain its authentication session. The app also uses localStorage for browser-only prototype data; localStorage is not a cookie. A first-visit notice lets you allow or decline optional activity logging. You can change that choice at Settings → Privacy. Declining clears the local activity log and prevents new optional event entries; core app data remains stored so the prototype can function.

Sharing and security

Supabase Auth provides account credential handling when configured, but GitHub Pages does not run a private server for the site's other features. Browser-only data is not synchronized to a protected HYDROBOTICS database. Anyone with access to this browser profile, or code running on this origin, may be able to access browser storage. Do not upload identity documents or enter sensitive information.

The demo's identity review and sharing approvals are simulated in browser storage. They are not real identity verification and do not provide a production security boundary.

Your choices and deletion

You can opt out of optional activity logging at any time in Settings → Privacy. You can remove HYDROBOTICS data saved in this browser using “Delete data stored in this browser” in that section; this signs you out and clears the app's local data. You can also clear this site's browser storage through your browser settings. Deletion here does not remove copies, exports, screenshots, or information stored elsewhere.

Privacy rights and contact

Privacy laws such as the GDPR, South Africa's POPIA, and California's CCPA may provide rights concerning personal information, depending on your location and circumstances. This demo has no backend operator workflow to verify requests, fulfill statutory deadlines, or process formal rights requests. Before using this prototype with real people or data, the responsible organization should identify a privacy contact, define retention and security controls, and obtain jurisdiction-specific legal review.
